\section*{教学思考}

\subsection*{教学理念}
在我的教学中，基于问题的学习模式让学生面对实际问题，并引导他们形成结合理论与实践的解决方案。
我发现，当学生理解一个主题的重要性并主动负责自己的学习时，学习效果最好。
这一认识影响着我的课程设计和项目指导。
我的目标是帮助学生在毕业时既具备深入的技术能力，也能保持自主学习的能力。

\subsection*{课程建设}
我从零开始为“AI Systems \& Infrastructure”课程准备全部材料，以博客文章形式编写了十余个模块。
博客式课程材料便于持续更新，也更易获取，并可根据课程需求定制。
我在编写中力求专业、全面、直观，并适度加入幽默表达。
大多数学生缺少底层系统知识，因此我采用贴近学生经验的直观方式讲解概念。

\vspace{\entryskip}
每个模块围绕从业人员面对的具体问题展开，并配有相互衔接的实践练习。
学生先学习 HTTP 协议并构建调用人工智能 API 的命令行聊天机器人，随后角色互换，由 API 使用者转为服务提供者，开发自己的图像分类 API 服务器，实现身份验证、数据库支持的用户管理和请求频率限制。
下一个模块要求学生将服务器封装为 Docker 容器，之后的模块指导他们将系统部署到 Raspberry Pi 或 NVIDIA Jetson 等实体硬件上，并处理架构兼容和远程访问问题。
课程最后以小型项目收尾，各组综合运用所学技能，在自己控制的硬件上部署具备多种功能的人工智能系统。
课堂力求富有启发性和激励作用，使学生能在有限时间内理解核心内容，并为进一步学习各主题奠定基础。
口试考查学生能否自信地解决实际问题，而非背诵语法或概念名称。

\vspace{\entryskip}
该课程获得了积极评价。
这是课程的第二轮教学。
第一轮评价较差，当时的材料也未达到我的标准，因此我重新设计了全部课程。
学校的正式学期报告非常积极，尤其肯定了课程材料，相关表扬甚至出现在批评意见部分。

\subsection*{指导方法}
我指导本科生和硕士生学期项目，并撰写版式清晰、直观的项目计划，以实际问题为基础明确研究方向。
我的项目指导同样采用基于问题的学习方法。
我从易于理解的实际问题和案例出发，强调合理规划项目所需的关键考量及其理由，并为学生提供足够资源，让他们自行探索如何应用这些考量。

\vspace{\entryskip}
我努力做到平易近人并为学生提供支持，同时给学生留下自主决策的空间。
我会提供技术路线建议，并在学生遇到障碍时给予帮助，同时鼓励他们主导项目方向。
在我提出“A Camera That Sees Behind”项目时，原始目标是开发可部署于嵌入式设备的轻量模型以移除图像中的对象。
两个小组根据各自分析，分别将项目拓展为符合 GDPR 要求的隐私保护方向，以及研究嵌入式硬件部署限制的方向。
学生认为我的指导很有帮助，也认为我平易近人、易于沟通。
我也看到他们在独立应对部署挑战的过程中逐步建立信心。

\subsection*{教学计划}
我对这些教学实践的成效感到满意，并计划在持续改进的同时保留这些做法。
今后，我将继续遵循三项核心原则，并坚持已证明有效的具体做法，包括博客式课程材料、富有启发性和参与感的课堂、公开透明的课程与考试形式和要求，以及均衡且循序渐进的模块安排。
我相信，这套方法能够帮助我讲授好各类计算机科学课程。
我也有兴趣开发时空数据挖掘和人工智能基础设施方向的新课程。

\vspace{\entryskip}
我还在准备承担硕士学位论文和博士生指导工作，并将学期项目、科研指导和计算机科学与工程实践中的共通原则延续下去，包括清晰定义问题，明确形成有说服力结论的路径，批判性分析设计和实现选择，以及保证报告和展示的质量。
我希望通过以科研为基础的教学和认真投入的指导，帮助学生成长为能够批判性思考技术并将知识用于实际问题的毕业生。
